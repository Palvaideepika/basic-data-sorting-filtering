# Basic Data Sorting and Filtering – Excel

## 📌 Project Overview

This project demonstrates basic data sorting and filtering techniques using Microsoft Excel on the Sample Superstore dataset.

The objective was to explore sales and profit data, apply sorting and filtering techniques, and answer basic business questions using Excel.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- Sorting and Filtering
- Excel formulas
- SUBTOTAL function

## 📊 Dataset

The project uses the Sample Superstore dataset containing sales-related information such as:

- Order ID
- Order Date
- Customer Name
- Segment
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

## 🔍 Tasks Performed

The following activities were completed:

1. Organized the Superstore dataset in Excel.
2. Created a separate analysis sheet while keeping the raw data unchanged.
3. Converted the analysis data into an Excel table.
4. Applied sorting to analyze sales and profit values.
5. Used filters to analyze specific regions and categories.
6. Applied a Sales greater than $1,000 filter.
7. Used multiple filters, including Region and Category.
8. Created PivotTables to summarize sales and profit.
9. Answered five business questions based on the dataset.

## 💡 Business Questions and Findings

| No. | Business Question | Finding |
|---|---|---|
| 1 | Which region has the highest total sales? | West – $725,457.82 |
